Agent Energy Companion · Setup guide

Set up closed-lid support.

The companion lets Agent Energy keep your Mac awake when you close the lid. Follow all four steps below, then use the can to start a session.

Moving the app to Applications does not finish setup. You also need to open it and click Install Companion.

01 / DOWNLOAD & MOVE

Put it in Applications

Download and open the ZIP file. Drag Agent Energy Companion.app into your Applications folder.

02 / OPEN & INSTALL

Open the companion

In Applications, double-click Agent Energy Companion. In its setup window, click Install Companion.

This is the step that connects the companion to Agent Energy. Downloading or moving it alone won’t connect it.

03 / APPROVE

Allow the helper if asked

If macOS requests approval, go to System Settings → General → Login Items & Extensions, allow Agent Energy Companion, and complete any password or Touch ID prompt.

Return to the companion and check that it says Ready. If you’ve approved it before, macOS may skip the approval prompt.

04 / START A SESSION

Check Ready, then click the can

Open Agent Energy’s lightning-bolt menu. Look for Closed-lid support ready, then click the can. IN FLIGHT means the session is active.

If a session was already running, switch to Standby and start a new one. You can quit the companion’s setup window, but keep its app in Applications.

What changes?

Without the companion, Agent Energy keeps your Mac awake while the lid stays open. With the companion connected, an active session also prevents sleep when you close the lid. Your screen can still sleep and your screen-lock settings stay in place.

During a closed-lid session, manual Sleep is also blocked. Click the can to return to Standby, or quit Agent Energy, to restore the previous sleep setting. Switch to Standby before putting your Mac in a bag.

A few useful details

Why a separate download?

The main app is sandboxed. The companion handles the system power setting and requires your separate installation and administrator approval. The main app does not download or install executable code.

What if the app quits unexpectedly?

The helper monitors the connection and a short-lived session lease. It attempts to restore the previous setting when the connection closes or the lease expires. It also keeps a local recovery record for helper restarts.

How do I remove it?

Switch Agent Energy to Standby. Open Agent Energy Companion and choose Remove Companion. Once removal succeeds, move the companion app to the Trash.

Does it collect data?

No accounts, analytics, or activity uploads. The recovery record stays on your Mac. This page and its downloads are hosted by GitHub, which handles those visits under its own privacy policy.

I downloaded it, but Agent Energy still asks me to set up.

Open Agent Energy Companion from Applications and click Install Companion. Moving the app there alone is not enough. Complete any macOS approval prompt, wait for Ready, then reopen Agent Energy’s menu. If an error remains, report it here.
